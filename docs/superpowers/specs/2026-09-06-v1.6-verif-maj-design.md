# Spec — v1.6 « Vérification de mise à jour »

> Établie le 2026-09-06. Sous-projet de la feuille de route
> (`docs/superpowers/specs/2026-06-21-roadmap.md`). Cycle *spec → plan →
> implémentation → revue*. Cible de version : **1.6.0**.

## Périmètre

Le projet publie maintenant de vraies releases GitHub taguées (v1.5.0 est la
première). Les utilisateurs qui ont téléchargé une version antérieure
(ZIP, sans Git) n'ont aujourd'hui aucun moyen de savoir qu'une nouvelle
version existe, sinon en revisitant la page GitHub de temps en temps.

Objectif : le scraper et le viewer vérifient automatiquement, une fois par
jour au plus, si une version plus récente est publiée sur GitHub, et
affichent une notice discrète si c'est le cas — **sans jamais télécharger ni
modifier de fichier automatiquement** (l'utilisateur re-télécharge ou fait
`git pull` lui-même).

Hors-scope : mise à jour automatique (remplacement de fichiers), notification
pour les versions préliminaires/pré-release, exécutable `.exe` (v2.0, pas
encore publié).

## Principes directeurs

- **Jamais bloquant.** Timeout court (2 s), toute erreur réseau est avalée
  silencieusement — le script continue normalement, hors-ligne ou non.
- **Un seul appel réseau par jour, partagé.** Résultat mis en cache dans
  `.cdp-scraper/maj.json` ; scraper et viewer lisent/écrivent le même
  fichier (cascade cwd→HOME identique à `cdp_config`/`cdp_coffre`). Le cache
  est mis à jour **même en cas d'échec** (pour ne pas retenter l'appel à
  chaque run tant qu'on est hors-ligne).
- **Zéro dépendance ajoutée.** Nouveau module `cdp_maj.py` en stdlib pur
  (`urllib.request`, `json`) — le viewer doit rester sans dépendance externe ;
  le scraper n'a donc pas besoin d'utiliser `requests` ici non plus (cohérence
  d'un seul module partagé).
- **Désactivable et transparent.** Flags `--sans-verif-maj` (scraper,
  cohérent avec `--sans-colles`) et `--no-verif-maj` (viewer, cohérent avec
  `--no-browser`). La mention RGPD est mise à jour pour rester honnête (comme
  pour le coffre en v1.4).
- **Tests 100 % hors-ligne** : l'appel réseau est isolé dans une fonction
  unique, mockée dans les tests.

## 1. Module `cdp_maj.py`

### Fichier de cache

`.cdp-scraper/maj.json`, même cascade que `cdp_config.chemin_config` /
`cdp_coffre.chemin_coffre` (pas d'override CLI dédié : ce cache n'est pas une
donnée que l'utilisateur a besoin de déplacer).

```json
{
  "derniere_verif": "2026-09-06T18:30:00",
  "derniere_version_connue": "1.5.0"
}
```

Pas de champ `version` de schéma ici (contrairement à `config.json`/`coffre.json`) :
c'est un cache jetable et non critique, pas une donnée utilisateur — un
format inattendu se régénère simplement au prochain essai, sans notion de
compatibilité à gérer.

- `derniere_verif` : horodatage du dernier **essai** (réussi ou non).
- `derniere_version_connue` : dernier tag obtenu avec succès (absent tant
  qu'aucun appel n'a réussi).

### API

- `chemin_maj(override: str | None = None) -> Path` — cascade cwd→HOME,
  calquée sur `cdp_config.chemin_config`.
- `charger(chemin: Path) -> dict` — absent/illisible → `{}` (pas d'erreur
  fatale ; les clés manquantes sont lues via `.get()` avec des valeurs par
  défaut dans `verifier_maj`).
- `enregistrer(chemin: Path, donnees: dict) -> None` — écriture atomique
  (`.part` → renommage), comme les autres modules.
- `_version_tuple(s: str) -> tuple[int, ...]` — parse `"1.5.0"` ou `"v1.5.0"`
  en `(1, 5, 0)` ; renvoie `()` si le format est inattendu (comparaison
  toujours `False` dans ce cas, jamais d'exception).
- `derniere_version_github(depot: str, timeout: float = 2.0) -> str | None`
  — `GET https://api.github.com/repos/<depot>/releases/latest` (`depot` =
  `"Bastien-Gaffet/cdp-scraper"`), en-tête `User-Agent` requis par l'API
  GitHub. Renvoie `tag_name` sans le préfixe `v`, ou `None` pour **toute**
  erreur (réseau, timeout, JSON invalide, clé absente, code HTTP ≠ 200).
- `verifier_maj(version_locale: str, chemin_cache: Path, depot: str) -> str | None`
  — logique complète :
  1. Charge le cache.
  2. Si `derniere_verif` date de moins de 24 h → **pas d'appel réseau**,
     réutilise `derniere_version_connue` du cache.
  3. Sinon → appelle `derniere_version_github`. Écrit systématiquement
     `derniere_verif = maintenant` (succès ou échec) ; met à jour
     `derniere_version_connue` **seulement en cas de succès**.
  4. Si une version connue existe et que
     `_version_tuple(connue) > _version_tuple(version_locale)` → renvoie la
     version connue ; sinon `None`.

## 2. Intégration `cdp_scraper.py`

- Nouveau flag `--sans-verif-maj` (`action="store_true"`).
- Import `cdp_maj` en tête de fichier (comme `cdp_config`/`cdp_coffre`, aucun
  coût : pas de dépendance tierce dans ce module).
- Dans `main()`, juste après la ligne de crédit déjà affichée sous la
  bannière :

```python
if not args.sans_verif_maj:
    nouvelle = cdp_maj.verifier_maj(__version__, cdp_maj.chemin_maj(), DEPOT_SLUG)
    if nouvelle:
        print(jaune(
            f"  Une nouvelle version est disponible : {nouvelle} "
            f"(vous avez {__version__}) — {DEPOT}/releases/latest\n"))
```

- Nouvelle constante `DEPOT_SLUG = "Bastien-Gaffet/cdp-scraper"` à côté de
  `DEPOT` (déjà utilisé dans le User-Agent HTTP vers cahier-de-prepa).

## 3. Intégration `cdp_viewer.py`

- Nouveau flag `--no-verif-maj` (`action="store_true"`, cohérent avec
  `--no-browser` déjà présent dans ce fichier).
- Import `cdp_maj` (aucune dépendance ajoutée : le module est stdlib pur).
- Dans `main()`, juste après `print(f"cdp-viewer en écoute sur {url} …")` et

if not args.no_verif_maj:

## 5. Tests

`tests/test_cdp_maj.py` (nouveau, hors-ligne, aucun appel réseau réel) :

- `_version_tuple` : cas normal, préfixe `v`, format inattendu → `()`.
- `charger`/`enregistrer` : absent → cache vide, round-trip, écriture
  atomique (pas de `.part` résiduel).
- `verifier_maj` :
  - cache absent → appelle `derniere_version_github` (mocké), écrit le
    cache, renvoie la nouvelle version si elle est supérieure.
  - version distante == version locale → renvoie `None`.
  - version distante < version locale → renvoie `None` (jamais de
    « rétrograder »).
  - cache < 24 h → **n'appelle pas** `derniere_version_github` (assertion
    `not_called`), réutilise la valeur en cache.
  - cache > 24 h → rappelle `derniere_version_github`.
  - `derniere_version_github` renvoie `None` (échec réseau) → `derniere_verif`
    est quand même mis à jour dans le cache (pour ne pas retenter à chaque
    run), `derniere_version_connue` reste celle d'avant (ou absente), la
    fonction ne lève jamais.
- `derniere_version_github` : mock de `urllib.request.urlopen` — succès
  (JSON valide avec `tag_name`), timeout, JSON invalide, code HTTP erreur →
  toujours `None` sauf le cas succès, jamais d'exception qui remonte.

`tests/test_cdp_scraper.py` / `tests/test_cdp_viewer.py` (ajouts) :

- `--sans-verif-maj` / `--no-verif-maj` : quand présent, `cdp_maj.verifier_maj`
  n'est **pas appelé** (mock + `assert_not_called`).
- Sans le flag, `verifier_maj` mocké renvoyant une version → la notice
  s'affiche (capture de stdout) ; renvoyant `None` → rien ne s'affiche.

## Compatibilité

- Comportement par défaut **changé** (nouveauté assumée) : un appel réseau
  vers GitHub a désormais lieu au plus une fois par jour, sauf désactivation
  explicite. Documenté dans l'avertissement et le README.
- `.gitignore` couvre déjà `.cdp-scraper/` : `maj.json` n'est jamais suivi
  par git.
- Aucun changement de schéma pour `config.json`/`coffre.json`.
- Le viewer reste sans dépendance tierce (aucun `pip install` supplémentaire
  déclenché par cette fonctionnalité, contrairement au coffre).

## Critères de réussite

- Une version obsolète affiche la notice avec le bon numéro et le lien vers
  la page des releases, au scraper comme au viewer.
- Une installation à jour n'affiche rien.
- Hors-ligne, aucun ralentissement perceptible au-delà du premier essai de
  la journée (timeout 2 s max), et aucune erreur visible.
- `--sans-verif-maj` / `--no-verif-maj` supprime tout appel réseau pour ce
  run.
- Suite de tests hors-ligne verte, aucun appel réseau réel dans les tests.
